# Balgona Cricket Cards — Name-first Reveal Showcase

A mobile-first static player showcase. Visitors see player names only; tapping a name opens a cinematic, tier-colored card reveal with the supplied stats and special ability. This is a showcase only and does not include battles or multiplayer.

## Roster
Meghnath, Bappa, Raj, Priyangshu, Saikot, Rahul, Tirtha, Riku, Fata, and Sheba. Data transcribed from the user's handwritten roster. The displayed player index is the rounded mean of batting, bowling, fielding, power, and timing; it is a display calculation, not an official rating.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Publish on GitHub Pages
Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the root of a GitHub repository. Under Settings → Pages, choose Deploy from a branch, select `main` and `/(root)`, and save.

## Notes
The names-only list reveals a premium card on tap. Iconic, Legend, Black, Silver, and Bronze tiers have distinct visual treatments. The current roster is embedded in `app.js`; updating the source and redeploying changes the public roster. No photographs are required.
